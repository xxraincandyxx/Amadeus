# Amadeus User Guide

This directory is the canonical source for user-facing product guidance bundled into the web and macOS app.

Each chapter has matching English and Simplified Chinese manuscripts. Keep chapter IDs and heading structure aligned across locales. Developer architecture, API contracts, contribution procedures, test plans, and design-system documentation remain in the main `docs/` directory and are linked from the app as developer references.

## Chapters

1. Getting started
2. Conversations and context
3. Multi-agent work
4. Tools and approvals
5. Commands and shortcuts
6. Settings and troubleshooting
