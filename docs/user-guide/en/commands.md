# Commands and shortcuts

Type `/` as the first character in the composer to open the command palette. Use Arrow Up and Arrow Down to move, Enter or Tab to select, and Escape to dismiss.

| Command | Action |
| --- | --- |
| `/help` | Open this guide at the command reference |
| `/new-agent [name]` | Create and open an independent session |
| `/context` | Show current session and token usage |
| `/compact` | Summarize older context and recover space |
| `/tools` | Inspect the active tool catalog |
| `/prompt` | Inspect the active model and prompt profile |
| `/export [markdown\|json]` | Download the conversation |
| `/settings` | Open connection and language settings |
| `/contribute` | Open contribution resources |
| `/cancel` | Stop the active agent turn |
| `/close` | Close the current session |

Commands run locally in the app and are not sent to the model. A slash elsewhere in a message remains ordinary text.
