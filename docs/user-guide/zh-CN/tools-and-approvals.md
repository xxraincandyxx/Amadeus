# 工具与审批

智能体使用工具检查工作区、编辑文件、运行命令以及访问已配置的服务。工具活动会显示在对话中。

## 查看工具调用

点击工具行可展开输入和输出。文件写入和编辑会显示逐行差异：删除行使用红色，新增行使用绿色。运行中的工具会保持可见，直到执行完成。

## 处理审批

在继续执行前，审批卡片会说明工具、操作和输入。

- **允许一次**仅批准当前请求。
- **始终允许**在当前策略范围内批准后续匹配请求。
- **拒绝**会阻止操作，并将决定返回智能体。

批准前应检查路径、命令和网络目标。如果子智能体请求审批，请从智能体工作区打开对应子会话。

## 停止当前工作

使用停止按钮或 `/cancel` 取消当前任务。已经完成的文件修改不会自动回滚，因此继续前应检查工具结果。
