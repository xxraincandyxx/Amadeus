# 对话与上下文

对话是单个智能体会话的工作记录。用户请求、最终回答、思考披露、工具活动和审批请求会按时间顺序显示。

## 思考披露

当模型服务商提供独立的推理流时，Amadeus 会显示**思考**行。完成后的思考默认折叠，点击即可查看。未提供独立推理内容的模型不会显示此区域。

## Markdown 回答

回答支持标题、强调、链接、列表、任务列表、表格、引用、行内代码和代码块。代码块提供复制操作，原始 HTML 会被转义。

## 上下文用量

使用 `/context` 查看消息数、待审批项、令牌用量和上下文百分比。当长对话需要更多空间时，使用 `/compact`。压缩会总结较早的上下文并保留近期工作。

## 导出记录

使用 `/export markdown` 导出易读文稿，或使用 `/export json` 导出结构化会话数据。导出不会修改对话。
