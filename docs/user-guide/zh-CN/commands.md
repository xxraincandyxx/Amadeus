# 命令与快捷操作

在输入框第一个字符处输入 `/` 可打开命令面板。使用上、下方向键移动，按 Enter 或 Tab 选择，按 Escape 关闭。

| 命令 | 操作 |
| --- | --- |
| `/help` | 打开本指南的命令参考 |
| `/new-agent [name]` | 创建并打开独立会话 |
| `/context` | 显示当前会话和令牌用量 |
| `/compact` | 总结较早上下文并释放空间 |
| `/tools` | 查看当前工具目录 |
| `/workflow` | 打开可视化工作流设计器 |
| `/prompt` | 查看当前模型和提示词配置档 |
| `/export [markdown\|json]` | 下载当前对话 |
| `/settings` | 打开连接和语言设置 |
| `/contribute` | 打开贡献资源 |
| `/cancel` | 停止当前智能体任务 |
| `/close` | 关闭当前会话 |

命令在应用本地执行，不会发送给模型。消息其他位置出现的斜杠仍按普通文本处理。
