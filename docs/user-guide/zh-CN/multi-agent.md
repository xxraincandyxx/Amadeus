# 多智能体协作

智能体工作区会展示任务委派关系。根会话是**协调智能体**。当它委派专项任务时，Amadeus 会创建独立的子会话，包含自己的对话、工具、状态和上下文。

## 跟踪委派

从侧边栏打开**智能体**，即可查看层级结构。每一行显示智能体角色、委派任务、父级、子级数量和当前状态。点击任意行可打开对应智能体的对话。

## 理解职责

- 协调智能体负责总体目标并汇总委派结果。
- 子智能体负责专项任务，并将结果返回父智能体。
- 嵌套子智能体会在层级中继续缩进。
- 等待审批的子智能体可以单独打开并处理，不会丢失父会话。

## 选择新会话或委派

相互独立的工作应创建新的协调智能体。多个专项任务共同服务于一个目标时，应由协调智能体进行委派。

## 关注状态

优先处理运行中和需要审批的智能体。已完成的会话会保留为工作证据。失败的会话也会保留对话，便于检查原因或从父任务重试。
