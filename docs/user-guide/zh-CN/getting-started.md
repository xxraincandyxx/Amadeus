# 快速开始

Amadeus 是一个用于协作 AI 智能体的本地工作区。每个会话会集中保存一段对话、工具活动、审批和上下文。

## 开始会话

选择**新建会话**，输入便于识别的任务名称，然后在输入框中描述需求。清晰的请求应包含目标、相关文件或范围，以及你期望的验证方式。

```text
检查会话 API，修复历史记录刷新失败的问题，并运行相关 Web 测试。
```

按 Enter 发送，按 Shift + Enter 换行。停止按钮会取消当前任务，但不会删除会话。

## 了解工作区

- 侧边栏列出协调智能体和被委派的子智能体。
- 状态点表示空闲、运行中、已完成、需要审批或失败。
- 顶栏显示当前会话；如果它是子智能体，还会显示父智能体。
- 详情面板显示角色、父级、子级、消息数、工具调用数和令牌用量。

## 分隔不同工作

当任务需要独立上下文或独立负责人时，创建新会话。当后续请求依赖当前对话或工具结果时，继续使用现有会话。
