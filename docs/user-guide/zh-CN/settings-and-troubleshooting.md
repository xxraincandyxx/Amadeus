# 设置与故障排查

从侧边栏底部打开**连接设置**，或使用 `/settings`。

## 连接

原生应用会管理内置的本地服务器。Web 客户端连接到已配置的 HTTP API 地址。保存前可使用**测试**确认地址是否可用。

远程服务器应使用 HTTPS，并在网络边界启用身份验证。不要将未认证的本地开发服务器暴露到不可信网络。

## 语言

在**界面语言**中选择 English 或简体中文。应用会在本地保存选择，并加载对应语言的指南文稿。

## 常见问题

### API 不可用

确认服务器正在运行，并检查配置的地址是否可访问。开发环境的默认地址是 `http://127.0.0.1:3000`。

### 实时连接中断

事件流会自动重试。如果历史记录正常但实时更新停止，请测试连接并重新连接。

### 智能体正在等待

检查当前对话中是否有审批卡片。在多智能体任务中，打开智能体工作区并查找需要审批的子智能体。

### 上下文即将用尽

先运行 `/context`，如果较早的对话可以总结，再运行 `/compact`。
